One original warning label for a human, built for the [make.fun "Warning Label for Humans: One Line, Big Laugh" bounty](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85). A label that reads like it belongs on the packaging — because this human clearly needs one.

## The line

> WARNING: This human runs on eight hours of sleep it never gets, coffee it cannot taste anymore, and deadlines it invented itself.

129 characters, one line. Three escalating "fuel sources", each one a self-inflicted contradiction: sleep it never gets, coffee it can no longer taste, deadlines it made up itself. The joke lands on the last clause — the human is its own worst manufacturer.

## Run

`main.ts` (Node 22, no network, no dependencies) writes the single entry line to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
